## Accessing the Dungeons

To enter the Dungeons, head to the dungeon gate located at `/warp dungeon`. You'll need to possess **Rusty Keys** (Dungeon Keys), which can be purchased from the shopkeeper at `/warp dungeon` using in-game currency.

## Solo or Party Adventure

You can brave the Dungeons solo or join forces with your friends. To form a party, invite your companions using the command `/party invite <username>`. Each party can accommodate up to **four members**, including the leader.

Ensure that all party members have the required Dungeon Keys before proceeding to the dungeon keeper. Right-click on the dungeon keeper and select the desired dungeon to enter.

Choose your path between the **Coven**, where magic reigns supreme, and the **Knight**, where bravery and skill are paramount.

## Dungeon FAQs

<AccordionGroup>
  <Accordion title="Will I lose items or XP if I die?">
    You won't lose any items or experience points if you perish within the Dungeon.
  </Accordion>

  <Accordion title="How many lives do I get?">
    You'll have only one life per Dungeon entry.
  </Accordion>

  <Accordion title="Can I use all my commands inside the Dungeon?">
    No — only Dungeon-specific commands are functional within the Dungeon.
  </Accordion>

  <Accordion title="How do I exit the Dungeon?">
    Use the command `/leave` to exit the Dungeon at any time.
  </Accordion>

  <Accordion title="I'm stuck inside the Dungeon. What do I do?">
    If you find yourself stuck within the Dungeon, use the command `/stuck` to seek assistance.
  </Accordion>

  <Accordion title="The next wave won't start. Is that a bug?">
    It might be. Exit the Dungeon using `/leave` and start a new run. If the issue persists, report it to an admin or mod.
  </Accordion>

  <Accordion title="I disconnected mid-dungeon. Can I rejoin?">
    Yes! If you accidentally disconnect while in the Dungeon, you'll have a **five-minute grace period** to rejoin the ongoing run.
  </Accordion>
</AccordionGroup>
